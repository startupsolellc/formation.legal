# Formation.Legal Content Roadmap

Last updated: 2026-04-26

## Founder-Level Bet

Formation.Legal should not be a blog. It should be a decision product wrapped in content.

The site wins if users think:

> "Before I choose an LLC service or state, I should check Formation.Legal because it shows the real costs, public-record risks, and hidden tradeoffs."

This means we publish fewer generic articles and more decision assets: calculators, cost indexes, teardown reports, comparison matrices, public-record explainers, and compliance trackers.

## Publishing Strategy

Use three content layers.

### Layer 1: Money Pages

These pages target users close to buying a registered agent or formation service.

Goal:

- Drive Northwest affiliate clicks.
- Capture high-intent comparison and privacy queries.
- Build trust through transparent methodology.

Priority pages:

1. `Northwest Registered Agent vs LegalZoom`
2. `Northwest vs ZenBusiness`
3. `Best Registered Agent Service for Privacy`
4. `Do I Need a Registered Agent Service?`
5. `Registered Agent vs Virtual Address`
6. `LegalZoom Registered Agent Cost`
7. `The Real Cost of a Free LLC`

CTA:

- Primary: Northwest affiliate link.
- Secondary: Cost calculator or registered agent checklist.

### Layer 2: Proof Assets

These are defensible pages that other sites and AI systems can cite.

Goal:

- Build topical authority.
- Earn links.
- Differentiate from generic affiliate sites.
- Feed data into money pages.

Priority assets:

1. Two-Year LLC Cost Index
2. LLC Cost Calculator
3. Registered Agent Price Tracker
4. Privacy Exposure Score by State
5. Annual Report Deadline Tracker
6. State Anomaly Library
7. Formation Checkout Teardown Series
8. Official Source Map

CTA:

- Use contextual CTA modules, not aggressive buttons everywhere.
- Example: "If privacy is your main concern, compare Northwest's registered agent service."

### Layer 3: Support and Entity Pages

These pages help Google, AI systems, and users understand the topic universe.

Goal:

- Internal linking.
- Definitions.
- Long-tail capture.
- Answer extraction.

Priority pages:

1. What is a registered agent?
2. What is an LLC?
3. What is an EIN?
4. What is an operating agreement?
5. What is a foreign LLC?
6. What is an annual report?
7. What is franchise tax?
8. What is service of process?
9. What is a domestic LLC?
10. What is a certificate of good standing?

CTA:

- Mostly internal links.
- Soft CTAs only when intent is clearly commercial.

## Page Brief Template

Every article should be briefed before writing.

Required fields:

- Target query
- Search intent
- Buyer stage
- Commercial CTA
- Internal links in
- Internal links out
- Official sources
- Data required
- Screenshots required
- Last verified date
- Legal/tax disclaimer needed or not

Required content blocks:

- Short answer
- Who this is for
- Who this is not for
- Key table
- Source notes
- Decision section
- CTA module
- FAQ

## Content Formats to Prioritize

Prioritize:

- Calculators
- Comparison pages
- Data tables
- Teardown reports
- State anomaly explainers
- Decision trees
- Checklists
- Glossary pages only as support

Deprioritize:

- Generic "what is an LLC" traffic plays
- Thin state guides
- AI-written listicles
- "Best LLC service" pages without first-hand testing
- Legal or tax recommendations that require a professional license

## Internal Linking Model

Money pages should link to proof assets.

Example:

- Northwest vs LegalZoom links to:
  - Two-Year LLC Cost Index
  - LegalZoom Add-Ons Explained
  - Registered Agent Renewal Cost Tracker
  - What Is a Registered Agent?

Proof assets should link back to money pages.

Example:

- Privacy Exposure Score links to:
  - Best Registered Agent for Privacy
  - Registered Agent vs Virtual Address
  - Can I Use My Home Address for an LLC?

Glossary pages should link upward to hubs, not just sideways to other definitions.

## Editorial Standards

Every monetized comparison must have:

- A methodology section
- Clear affiliate disclosure
- Last reviewed date
- Official or primary source links
- Visible limitations
- No fake personal experience
- No legal or tax advice

If a page says "tested," it must include test date, what was tested, and evidence such as screenshots or data tables.

## Weekly Publishing Rhythm

Minimum viable cadence:

- 1 money page per week
- 1 proof/data update per week
- 1 support or glossary page per week

Better cadence after system is stable:

- Monday: money or comparison page
- Wednesday: proof asset, calculator update, or data page
- Friday: support page, glossary page, or FAQ expansion
